# VAMP-Diff: VampPrior Latent Diffusion for PPG

This repository contains the implementation of VAMP-Diff, 
a jointly trained variational diffusion model for 
photoplethysmography (PPG) signal generation.

## Paper
VAMP-Diff: VampPrior Latent Diffusion for 
Photoplethysmography Modeling  
Fatemeh Ghasemi Balouei, Nathan Willemsen, 
Mahesh Banavar, Bahman Moraffah  
Asilomar 2026

## Dataset
CapnoBase: https://doi.org/10.5683/SP2/MR0PTF

- Python 3.8+
- PyTorch
